欢迎来到我的博客！本站已完成架构升级，从数据库驱动迁移到 **Markdown 文件驱动 + Astro 静态站点生成**。

## 这次升级带来了什么

- **SEO 友好**：文章以静态 HTML 形式发布，搜索引擎可直接抓取
- **极速首屏**：默认零 JS，只有评论、点赞等交互部分作为 Vue 岛加载
- **内容所有权**：文章以 `.md` 文件形式存放在 git 仓库，可追溯、可迁移
- **全文搜索**：集成 Pagefind，构建时索引，客户端本地搜索

## 如何发布新文章

在 `src/content/blog/` 目录下创建 Markdown 文件，文件名格式建议 `YYYY-MM-DD-{slug}.md`。

```markdown
---
title: 文章标题
description: 一句话摘要
pubDate: 2026-06-14
tags: [前端, Vue]
---

正文内容...
```

第一个 tag 视作主分类（如"前端"），其余 tag 作为细粒度标签。

## 如何发布工具记录

在 `src/content/tools/` 目录下创建 Markdown 文件：

```markdown
---
name: 工具名称
url: https://example.com
category: 开发
icon: 🛠️
tags: [AI, 编辑器]
rating: 5
addedDate: 2026-06-14
---

使用记录正文...
```

提交 git 即可自动构建部署。
